# gladmill-skills

Free, open-source parts of the gladmill tools. Licensed under MIT (see LICENSE).

## Skills

- [`acad-pilot`](acad-pilot/): AutoCAD Pilot for Claude Code. Start AutoCAD, send it commands, query the drawing, take screenshots, click the ribbon and fill dialogs and alerts.
  **Download, demo recordings and release news: https://gladmill.com/pilot/** (the zip is also under [Releases](https://github.com/gladmill/gladmill-skills/releases)).

**This repository is public.** Do not commit paid products, paid skill files, private
licence text, customer data, or secrets here. Paid products live in a separate private repo.
